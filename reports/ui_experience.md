# Aurora 界面体验与内置模拟场景

当前数据完全由项目内代码构造，不读取 Excel。原 Excel 文件保留，但不参与当前生成或运行。

运行 python run.py，打开 http://localhost:8080 并 Ctrl+F5。项目附带模拟快照；修改场景后运行 python -m tools.build_demo_seed，再重启。

## 测试账号

选择账号即可进入，无需密码；这是演示身份切换，不是生产级认证。

| 账号 | 体验方向 |
| --- | --- |
| 林同学 | 借用资源、自己的视觉工作站、个人项目计划 |
| 周同学 | 私有 RTX 3090 贡献者、资源详情与共享时段 |
| 尹同学 | 公共大厅独立用户与个人贡献 |
| 蔡老师 | 实验室成员与协作小组 |

账号选择页还提供其他模拟成员。左下角账号和个人画像里的“切换账号”均可回到选择页。任务、个人 GPU、收入和信用会随身份改变。

## 页面结构

- 发现算力：算力广场、提交实验、队列与预测。
- 我的工作台：我的任务、个人画像、收支与收益。
- 协作与贡献：资源小组、共享审批、贡献资源。
- 帮助与记录：使用指南、事件记录。

侧栏按组折叠。广场支持搜索卡主、GPU 和节点，按型号、来源、空闲状态及“我的资源”筛选。

## GPU 详情

资源卡和卡槽都可以打开详情，支持键盘，Esc 关闭。

1. 计划与可用性：卡主项目进度曲线、阶段安排与后续计划，24/48/72 小时共享窗口。悬停或键盘聚焦可查看数据。
2. 当前任务：运行任务、模拟进度、借用者与租约；选中单卡后按卡槽过滤。
3. 规格与收益：GPU/显存、节点 CPU/内存、来源、卡主、共享规则及节点级收益。

公共资源没有个人卡主时显示管理归属和条件可用卡数。详情页可以把型号/显存带入表单；最终节点仍由策略与资源服务决定。

## 数据和边界

app/synthetic.py 合成账号、12 台工作站 / 34 张 GPU、32 条非终态分配，以及历史、收益和小组。app/data/experience_plans.json 定义项目计划样例。tools/build_demo_seed.py 使用纯 Python 生成快照，无需 Excel 或 openpyxl。

收益从同一组模拟使用记录汇总，贡献者与平台分账守恒。资源占用仍以 A 账本为准；详情、画像和预估不会占卡。图表是模拟记录、预设计划或有假设条件的推算，不是真实监控。

小组创建/成员权限、完整分层匹配、真实 Agent、自动派发与完整 TTL 自动释放不在本轮改版内。使用指南有简短说明。

## 验证记录

完整 Python 回归 162 项通过。真实 A/B 服务验证预估不占卡、私有审批前阻止提交、切换卡主批准、申请人提交、正确绑定、Job 运行及释放归还。

前端通过 JavaScript 语法检查和实际接口数据驱动的 DOM 桩冒烟，覆盖登录、切换账号、个人画像、资源详情、项目曲线、页签、48h 范围、表单带入、角色指南与退出。这不等同浏览器视觉验证；本机 Computer Use 图形管道不可用，未完成页面布局目视检查。

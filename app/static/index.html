排队还没有占卡；分配成功才开始计算租约。租约到期时间与任务完成时间不同。

几件容易混淆的事

公共卡和私有卡有什么区别？

公共卡按当前策略申请；个人私有卡保留卡主授权。组内实验室公共卡与个人私有卡分别展示归属。

详情里的曲线，代表什么？

项目曲线来自预制演示计划；可共享时段按卡主声明和现有租约推算。它们不是实际 GPU 监控，也不保证资源一定可用。

贡献收益如何查看？

个人画像显示该账号的历史收支和拥有的 GPU；收支页可展开查看资源来源与平台分配。历史汇总不会随现场新任务自动结算。

这次 Demo，可以怎样体验

选择账号 → 查看卡主计划 → 预估方案 → 申请资源 → 在「我的任务」里查看状态。私有卡需切换到对应卡主审批，再切回申请人提交。

小组创建 / 权限、自动派发和完整 TTL 自动释放尚未完成；不会在界面上当成已实现功能。
